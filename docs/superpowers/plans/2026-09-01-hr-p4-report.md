# 人事模块 P4（财务凭证报表 + 考勤机API预留）Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 交付工资手工调整（留痕）、财务凭证生成（计提/发放）、3 种 Excel 报表导出、历史归档检索、考勤机批量同步预留端点（功能点15-20）。

**Architecture:** 新增 `hr_payslip_adjust`（调整日志）、`hr_voucher`（月度凭证，(month, voucher_type) 唯一、重生成覆盖）、`hr_attendance_import`（同步批次留痕）3 张表；凭证 entries 与工资调整重算抽为 `hr_payroll.py` 纯函数（TDD，借贷平衡断言）；Excel 用 openpyxl 内存构建 + `Response(blob, mimetype)` 流式下载（项目既有模式）；考勤机 sync-api/import 共用批量导入 Service（source 区分 api_sync/manual_excel，预留不绑品牌）。

**Tech Stack:** 同 P2/P3 + openpyxl 3.1.5（已在依赖）。

**设计依据:** `docs/superpowers/specs/2026-08-31-hr-module-design.md`（P4 = 功能点15-20）

**关键决策（实现层）：**
1. 凭证口径（全月汇总一张，不分部门）：`accrue` 计提 = 借「管理费用—工资」gross / 贷「应付职工薪酬」gross；`pay` 发放 = 借「应付职工薪酬」gross / 贷「应交税费—个税」tax、贷「其他应付款—社保」social、贷「其他应付款—公积金」fund、贷「银行存款」net。entries 为 `[摘要, 科目, 借, 贷]` 数组的 JSON；借贷必须平衡（纯函数断言）
2. 凭证仅从 **published** payslips 汇总（draft 不可入凭证）；(month, voucher_type) 唯一，重生成覆盖（幂等）
3. 手工调整：仅 published 可调；field 白名单 `{attendance_deduction, social_insurance, housing_fund, income_tax}`；强制 reason；调整后 `net_pay = gross_pay - 四项扣款之和` 重算落盘；写 hr_payslip_adjust 日志（old/new 值 + operator）；调整后若该月已生成 pay 凭证，响应带 `voucher_stale: true` 提示重生成（不自动重生成）
4. 报表 3 种（`GET /hr/report/export?type=`）：`attendance` 考勤月汇总 / `payroll` 工资发放明细 / `insurance` 社保公积金个税汇总（基数取 hr_salary_profile，无档案行留空）；仅 published+draft 中 status=published 优先展示全部行，attendance 表以 hr_attendance_month 为主
5. 历史归档检索 `GET /hr/archive/search`：month/department/keyword 三条件可选（至少一个），以 hr_attendance_month 为主表 join 员工+用户，附该员工当月 payslip 状态
6. 考勤机预留：`POST /hr/attendance/sync-api`（source='api_sync'）与 `POST /hr/attendance/import`（source='manual_excel'，本期接受 JSON records 数组，Excel 文件解析后续迭代）共用 `HrAttendanceImportService.batch_punch`；body `{records: [{emp_no 或 employee_id, punch_time}]}`，逐条复用既有同分钟去重，失败行收集不中断；每批次写 hr_attendance_import 留痕
7. 权限：P4 全部 HR 端点挂 `hr_manage`（hr_finance 继续预留，与 P3 口径一致）

```python
VOUCHER_TYPES = ("accrue", "pay")
ADJUSTABLE_FIELDS = ("attendance_deduction", "social_insurance", "housing_fund", "income_tax")


def build_voucher_entries(payslip_rows, voucher_type):
    """全月汇总凭证 entries：[[摘要,科目,借,贷],...]。借贷平衡由构造保证。
    accrue: 借 管理费用—工资 = Σgross / 贷 应付职工薪酬
    pay:    借 应付职工薪酬 = Σgross / 贷 个税+社保+公积金+银行存款(=Σnet)"""
    if voucher_type not in VOUCHER_TYPES:
        raise ValueError(f"无效凭证类型：{voucher_type}")
    tot = lambda k: round(sum(float(p.get(k) or 0) for p in payslip_rows), 2)  # noqa: E731
    if not payslip_rows:
        return {"entries": [], "total_amount": 0.0}
    gross, net = tot("gross_pay"), tot("net_pay")
    social, fund = tot("social_insurance"), tot("housing_fund")
    tax, att = tot("income_tax"), tot("attendance_deduction")
    if voucher_type == "accrue":
        entries = [[f"计提{sum(1 for _ in payslip_rows)}人月度工资", "管理费用—工资", gross, 0.0],
                   ["结转应付职工薪酬", "应付职工薪酬", 0.0, gross]]
    else:
        # 发放：net 另含考勤扣款已从 gross 扣减（gross-扣款=实发口径），贷方合计恒等于借方
        entries = [["发放月度工资", "应付职工薪酬", gross, 0.0],
                   ["代扣个人所得税", "应交税费—应交个人所得税", 0.0, tax],
                   ["代扣社保个人部分", "其他应付款—社保", 0.0, social],
                   ["代扣公积金个人部分", "其他应付款—公积金", 0.0, fund],
                   ["实发工资", "银行存款", 0.0, round(gross - tax - social - fund, 2)]]
        assert abs(sum(x[2] for x in entries) - sum(x[3] for x in entries)) < 0.01, \
            "发放凭证借贷不平衡"
    return {"entries": entries, "total_amount": gross}
```

> 注意：考勤扣款（att）在 pay 口径已体现在 gross−扣款=net 的差额里，若发生 `gross != tax+social+fund+net + att` 的脏数据（历史手调），断言会响——实现时以实际字段口径为准，保证两条恒等式成立：`net = gross − tax − social − fund − att`（calc_payslip 已保证）。pay 凭证贷方"银行存款"应为 `net + att`（即 gross−tax−social−fund），与断言自洽。**实现者以测试为准调整实现，保证平衡恒等式。**

```python
def apply_adjustment(payslip_dict, field, new_value):
    """手工调整重算：field 白名单 + 非负校验；net = gross - 四项扣款。返回新 dict（不改入参）。"""
    if field not in ADJUSTABLE_FIELDS:
        raise ValueError(f"不可调整的字段：{field}")
    v = _num(new_value, None)
    if v is None or v < 0:
        raise ValueError("调整值必须是非负数字")
    r = dict(payslip_dict)
    r[field] = round(v, 2)
    r["net_pay"] = round(float(r["gross_pay"]) - r["attendance_deduction"]
                         - r["social_insurance"] - r["housing_fund"] - r["income_tax"], 2)
    return r
```

```python
    @classmethod
    def adjust(cls, payslip_id: str, field: str, new_value, reason: str,
               operator_id: str) -> object:
        """published 工资单手工调整：重算 net、落盘、写日志。非 published / 字段非法抛 ValueError。"""
        row = cls.model.get_or_none(cls.model.id == payslip_id)
        if not row:
            raise ValueError("工资单不存在")
        if row.status != "published":
            raise ValueError("仅已发布的工资单可手工调整")
        old = {k: float(getattr(row, k)) for k in
               ("gross_pay", "attendance_deduction", "social_insurance",
                "housing_fund", "income_tax", "net_pay")}
        new = apply_adjustment(old, field, new_value)
        # 条件更新防发布/调整竞态
        n = (cls.model.update(
                attendance_deduction=new["attendance_deduction"],
                social_insurance=new["social_insurance"],
                housing_fund=new["housing_fund"], income_tax=new["income_tax"],
                net_pay=new["net_pay"], update_time=current_timestamp())
             .where(cls.model.id == payslip_id, cls.model.status == "published").execute())
        if n == 0:
            raise ValueError("工资单状态已变化，请刷新后重试")
        HrPayslipAdjust.insert(id=get_uuid(), payslip_id=payslip_id,
                               employee_id=row.employee_id, month=row.month,
                               field=field, old_value=old[field],
                               new_value=new[field], reason=reason[:255],
                               operator_id=operator_id)
        # 该月 pay 凭证若已生成则标记过期（仅提示，不自动重生成）
        stale = HrVoucher.get_or_none(HrVoucher.month == row.month,
                                      HrVoucher.voucher_type == "pay") is not None
        row2 = cls.model.get_by_id(payslip_id)
        return row2, stale
```

```python
class HrAttendanceImportService(CommonService):
    model = HrAttendanceImport

    @classmethod
    def batch_punch(cls, records: list, source: str, operator_id: str,
                    file_name: str = "") -> dict:
        """考勤机批量导入：逐条按 emp_no/employee_id 定位 + 复用同分钟去重 punch。
        失败行收集不中断；批次落盘留痕。source ∈ api_sync|manual_excel。"""
        if source not in ("api_sync", "manual_excel"):
            raise ValueError("无效的导入来源")
        if not isinstance(records, list) or not records:
            raise ValueError("records 应为非空数组")
        if len(records) > 2000:
            raise ValueError("单批次最多 2000 条")
        ok, fails = 0, []
        for i, rec in enumerate(records):
            try:
                if not isinstance(rec, dict):
                    raise ValueError("记录须为对象")
                emp = None
                if rec.get("employee_id"):
                    emp = HrEmployee.get_or_none(HrEmployee.id == rec["employee_id"])
                elif rec.get("emp_no"):
                    emp = HrEmployee.get_or_none(HrEmployee.emp_no == rec["emp_no"])
                if not emp:
                    raise ValueError("员工不存在")
                pt = datetime.strptime(str(rec.get("punch_time") or ""),
                                       "%Y-%m-%d %H:%M:%S")
                HrAttendanceRecordService.punch(emp.id, source=source, punch_time=pt)
                ok += 1
            except ValueError as e:
                if len(fails) < 50:
                    fails.append({"row": i, "emp": str(rec.get("emp_no") or rec.get("employee_id") or ""),
                                  "punch_time": str(rec.get("punch_time") or ""), "error": str(e)})
        cls.insert(id=get_uuid(), source=source, file_name=file_name[:255],
                   total_rows=len(records), success_rows=ok, fail_rows=len(fails) if len(fails) < 50 else len(fails),
                   detail=json.dumps(fails, ensure_ascii=False), operator_id=operator_id)
        return {"total": len(records), "success": ok, "failed": fails}
```
