# 人事模块 P3（薪资核算引擎）Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 交付薪资档案管理、加班时长推导（补齐 P1 月汇总加班缺口）、考勤扣款/加班费/社保公积金/个税累计预扣计算引擎、应发实发核算、试算→核算入库→发布工资条闭环（功能点10-14，及功能点4的加班小时数）。

**Architecture:** 新增 `hr_salary_profile`（员工薪资档案）与 `hr_payslip`（月薪资单快照）2 张表；加班时长并入 `derive_day_status` 纯函数（工作日=last_out-work_end，休息日=首末打卡跨度）；核算引擎 `hr_payroll.py` 纯函数模块（TDD）：考勤扣款、加班费、社保公积金、个税累计预扣（7级超额累进，tax_snapshot 落盘跨月续算）；核算从已 confirmed 的 hr_attendance_month 行取考勤快照；前端 salary-view 员工看自己工资条（published 后），HR 档案管理+试算+核算+发布。

**Tech Stack:** 同 P2。

**设计依据:** `docs/superpowers/specs/2026-08-31-hr-module-design.md`（P3 = 功能点10-14）

**关键决策（实现层）：**
1. 个税累计预扣简化口径：tax_snapshot 记 `{cum_taxable, cum_tax_paid, this_tax, brackets}`，下月核算读本人上月 published/draft payslip 的 snapshot 续算；**上月无快照时按当月为首月起算**（设计原文「从1月按当前累计补算」需全量历史收入数据，当前系统无外部收入源，实际不可得，做偏差注释）
2. 手工覆盖：`manual_overrides` JSON 键 `social`/`fund`/`tax`（数值），命中时实发用覆盖值，计算原值仍存 snapshot 双值留痕
3. 加班费率按日归类：日汇总行的 work_date 是否节假日（rule 键 `holidays` 逗号分隔 YYYY-MM-DD 列表）→ holiday 费率；rest（周末）→ weekend 费率；否则 weekday 费率；费率单价走 rule_config
4. 核算前置条件：该月 hr_attendance_month 必须已 month-close（confirmed），否则拒绝核算——保证考勤快照稳定
5. DEFAULT_RULE 新增键：`social_rate`(0.105)、`fund_rate`(0.12)、`holidays`("")
6. hr_payslip 唯一约束 (employee_id, month)；核算重跑覆盖未 published 的行（幂等），published 拒绝覆盖
7. 金额全部 Decimal(10,2)，round(2)

```python
def _is_holiday(work_date, rule):
    return str(work_date) in [d.strip() for d in str(rule.get("holidays") or "").split(",") if d.strip()]


def _calc_overtime_hours(punches, work_date, rule, day_status):
    """工作日: last_out 超过 work_end 的时长；休息日/节假日: 首末打卡跨度。
    非 normal/late/rest 状态不计加班。保留 2 位小数。"""
    if day_status not in ("normal", "late", "rest") or not punches:
        return 0.0
    last = punches[-1]["punch_time"]
    if work_date.weekday() < 5 and not _is_holiday(work_date, rule):
        work_end = _parse_hm(rule.get("work_end"), time(18, 0))
        delta = last - datetime.combine(work_date, work_end)
        return round(max(0.0, delta.total_seconds() / 3600), 2)
    first = punches[0]["punch_time"]
    return round(max(0.0, (last - first).total_seconds() / 3600), 2)
```

```python
"""薪资核算引擎：纯函数、无 DB 依赖。金额一律 float 进 round(2) 出。"""
TAX_BRACKETS = [  # (累计应税所得额上限, 税率, 速算扣除数)
    (36000.0, 0.03, 0.0), (144000.0, 0.10, 2520.0), (300000.0, 0.20, 16920.0),
    (420000.0, 0.25, 31920.0), (660000.0, 0.30, 52920.0),
    (960000.0, 0.35, 85920.0), (float("inf"), 0.45, 181920.0),
]
MONTH_EXEMPTION = 5000.0  # 起征点/月


def calc_attendance_deduction(stats, base_salary, rule):
    """迟到 late_deduction/次 + 旷工 absent_deduction_multiplier 倍日薪/天。"""
    daily = float(base_salary) / float(rule.get("pay_days", 21.75) or 21.75)
    late = int(stats.get("late_count", 0) or 0) * float(rule.get("late_deduction", 20) or 0)
    absent = int(stats.get("absent_days", 0) or 0) * float(rule.get("absent_deduction_multiplier", 3) or 0) * daily
    return round(late + absent, 2)


def calc_overtime_pay(ot_breakdown, base_salary, rule):
    """weekday 小时*单价 + weekend 小时*单价 + holiday 小时*倍数*日薪。"""
    daily = float(base_salary) / float(rule.get("pay_days", 21.75) or 21.75)
    wd = float(ot_breakdown.get("weekday", 0) or 0) * float(rule.get("overtime_rate_weekday", 15) or 0)
    we = float(ot_breakdown.get("weekend", 0) or 0) * float(rule.get("overtime_rate_weekend", 20) or 0)
    ho = float(ot_breakdown.get("holiday", 0) or 0) * float(rule.get("holiday_overtime_multiplier", 3) or 0) * daily
    return round(wd + we + ho, 2)


def _tax_on_cumulative(cum_taxable):
    tax = 0.0
    for limit, rate, quick in TAX_BRACKETS:
        if cum_taxable <= limit:
            return max(0.0, cum_taxable * rate - quick)
    return tax


def calc_tax_this_month(gross, social, fund, prev_tax_paid, month_idx,
                        special_deduction=0.0):
    """个税累计预扣：返回 {this_tax, cum_taxable, cum_tax}。
    应税 = 累计应发 - 5000*月数 - 累计社保公积金 - 累计专项附加（调用方传入当月值，
    累计口径由 prev 快照+当月组成：此处简化为调用方直接给当月各项，内部按
    (month_idx-1) 的既往免税额近似——精确累计由 hr_service 层用上月 snapshot 串联）。"""
    raise NotImplementedError  # 实现者按测试补齐：见下方说明
```

**实现说明（实现者照此补齐 calc_tax_this_month 与 calc_payslip）**：

- `calc_tax_this_month(gross, social, fund, prev_tax_paid, month_idx, special_deduction, prev_snap=None)`：实际签名以测试为准调整。精确累计口径 = 上月 snapshot 的 `cum_taxable_gross/cum_social/cum_fund/cum_special`（调用方从上月 payslip.tax_snapshot 传入 `prev_snap`，None 时全 0）+ 当月值；`cum_taxable = cum_gross - 5000*month_idx - cum_social - cum_fund - cum_special`（下限 0）；`total = _tax_on_cumulative(cum_taxable)`；`this = max(0, round(total - prev_tax_paid, 2))`。返回 `{this_tax, cum_taxable, cum_tax: total, cum_gross, cum_social, cum_fund, cum_special}`（后四个供下月 snapshot 串联）。
- `calc_payslip(profile, stats, base_salary, rule, prev_snap, month_idx)`：
  - `allowances = post + meal + transport`；`gross = base + allowances + overtime_pay`，round(2)
  - `social = overrides.get("social") or social_base*rate`（rate = profile.social_rate 优先，回退 rule；None→0.105）；fund 同理
  - `tax = overrides.get("tax") or calc_tax_this_month(...)`（override 时 tax_snapshot 记 `{"overridden": true}` + 计算原值）
  - `deductions = attendance_deduction + social + fund + tax`；`net = round(gross - deductions, 2)`
  - 返回 dict：base_salary/allowances/overtime_pay/gross_pay/attendance_deduction/social_insurance/housing_fund/income_tax/net_pay/tax_snapshot（全 round(2)，tax_snapshot json.dumps ensure_ascii=False）

```python
        allowed = {"base_salary", "post_allowance", "meal_allowance",
                   "transport_allowance", "social_base", "fund_base",
                   "special_deduction", "social_rate", "fund_rate"}
        vals = {k: data[k] for k in allowed if k in data}
        if row:
            for k, v in vals.items():
                setattr(row, k, v)
            row.update_time = current_timestamp()
            row.save()
            return row
        rid = get_uuid()
        cls.insert(id=rid, employee_id=employee_id, **vals)
        return cls.model.get_by_id(rid)


class HrPayslipService(CommonService):
    model = HrPayslip

    @classmethod
    def _prev_snapshot(cls, employee_id: str, month: str):
        """本人 month 前一个有 snapshot 的 payslip（逐月回退最多12次）。"""
        y, m = int(month[:4]), int(month[5:7])
        for _ in range(12):
            m -= 1
            if m == 0:
                y, m = y - 1, 12
            row = cls.model.get_or_none(
                cls.model.employee_id == employee_id, cls.model.month == f"{y:04d}-{m:02d}")
            if row:
                try:
                    snap = json.loads(row.tax_snapshot or "{}")
                except ValueError:
                    return None
                if snap and not snap.get("overridden"):
                    return snap
                return None  # 上月被手工覆盖，累计链断点，按首月重算
        return None

    @classmethod
    def compute_for_employee(cls, emp_id: str, month: str, rule: dict) -> dict:
        """核算单人：读 confirmed 月汇总 + 薪资档案 + 上月 snapshot → calc_payslip。
        抛 ValueError 当月未归档/无薪资档案。"""
        mrow = HrAttendanceMonth.get_or_none(
            HrAttendanceMonth.employee_id == emp_id, HrAttendanceMonth.month == month)
        if not mrow or mrow.status != "confirmed":
            raise ValueError(f"员工 {emp_id} 的 {month} 考勤未月度归档，请先执行月度汇总")
        prof = HrSalaryProfile.get_or_none(HrSalaryProfile.employee_id == emp_id)
        if not prof:
            raise ValueError(f"员工 {emp_id} 未建薪资档案")
        try:
            overrides = json.loads(prof.manual_overrides or "{}")
        except ValueError:
            overrides = {}
        # 加班分类：按日汇总行归类 weekday/weekend/holiday
        year, mon = int(month[:4]), int(month[5:7])
        days = HrAttendanceDayService.month_days(emp_id, month)
        ot = {"weekday": 0.0, "weekend": 0.0, "holiday": 0.0}
        from api.db.services.hr_calculator import _is_holiday
        hset = {d.strip() for d in str(rule.get("holidays") or "").split(",") if d.strip()}
        for d in days:
            if d.overtime_hours and d.overtime_hours > 0:
                if str(d.work_date) in hset:
                    ot["holiday"] += float(d.overtime_hours)
                elif d.status == "rest" or d.work_date.weekday() >= 5:
                    ot["weekend"] += float(d.overtime_hours)
                else:
                    ot["weekday"] += float(d.overtime_hours)
        profile_dict = {
            "base_salary": float(prof.base_salary), "post_allowance": float(prof.post_allowance),
            "meal_allowance": float(prof.meal_allowance),
            "transport_allowance": float(prof.transport_allowance),
            "social_base": float(prof.social_base), "fund_base": float(prof.fund_base),
            "special_deduction": float(prof.special_deduction),
            "social_rate": float(prof.social_rate) if prof.social_rate is not None else None,
            "fund_rate": float(prof.fund_rate) if prof.fund_rate is not None else None,
            "overrides": overrides,
        }
        stats = {"attend_days": float(mrow.attend_days), "late_count": mrow.late_count,
                 "absent_days": mrow.absent_days, "overtime": ot}
        prev = cls._prev_snapshot(emp_id, month)
        month_idx = mon
        return calc_payslip(profile_dict, stats, profile_dict["base_salary"], rule,
                            prev_snap=prev, month_idx=month_idx)

    @classmethod
    def save_draft(cls, emp_id: str, month: str, r: dict, mrow) -> object:
        """upsert draft（published 拒绝覆盖）。"""
        row = cls.model.get_or_none(
            cls.model.employee_id == emp_id, cls.model.month == month)
        vals = {k: r[k] for k in ("base_salary", "allowances", "overtime_pay", "gross_pay",
                                  "attendance_deduction", "social_insurance",
                                  "housing_fund", "income_tax", "net_pay")}
        vals.update(overtime_hours=float(mrow.overtime_hours),
                    tax_snapshot=json.dumps(r.get("tax_snapshot", {}),
                                            ensure_ascii=False))
        if row:
            if row.status == "published":
                raise ValueError(f"员工 {emp_id} 的 {month} 工资单已发布，不可覆盖")
            for k, v in vals.items():
                setattr(row, k, v)
            row.update_time = current_timestamp()
            row.save()
            return row
        rid = get_uuid()
        cls.insert(id=rid, employee_id=emp_id, month=month,
                   attend_days=float(mrow.attend_days), late_count=mrow.late_count,
                   late_minutes=mrow.late_minutes, absent_days=mrow.absent_days,
                   leave_days=float(mrow.leave_days), status="draft", **vals)
        return cls.model.get_by_id(rid)
```
