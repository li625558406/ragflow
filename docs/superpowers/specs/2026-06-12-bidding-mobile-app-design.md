## 1. 技术架构

```
bidding_app/
├── lib/
│   ├── main.dart
│   ├── app.dart                    # MaterialApp + 主题 + 路由
│   ├── core/
│   │   ├── theme/                  # 设计令牌 (颜色/字体/间距)
│   │   ├── router/                 # go_router 路由
│   │   ├── api/                    # Dio HTTP + SSE 流式
│   │   ├── storage/                # flutter_secure_storage
│   │   └── utils/                  # RSA加密、格式化
│   ├── features/
│   │   ├── auth/                   # 登录/注册
│   │   ├── chat/                   # 对话 (核心)
│   │   ├── tools/                  # 费用计算器
│   │   ├── bid/                    # 招标查询
│   │   └── favorites/              # 收藏
│   ├── shared/
│   │   └── widgets/                # 通用组件库
│   └── models/                     # 数据模型
```

| 层 | 选择 | 原因 |
|----|------|------|
| 状态管理 | Riverpod | 类型安全, 流式数据友好 |
| 网络 | Dio + SSE | 拦截器自动 Token |
| 路由 | go_router | 声明式, 深度链接 |
| 安全存储 | flutter_secure_storage | 令牌加密 |
| Markdown | flutter_markdown | 消息渲染 |
| 文件 | file_picker | 附件上传 |
| 图标 | lucide_icons | 与 Web 端统一视觉 |

## 4. 通用组件规范

### 4.1 按钮

| 类型 | 样式 |
|------|------|
| Primary | `bg-[#0F172A]`, 圆角12dp, 高52dp, press→scale 0.97 |
| Secondary | `border-[#E2E8F0]`, 透明底, 同尺寸 |
| Text | 仅文字, `color-[#0369A1]` |
| Icon Button | 44×44dp 最小触摸区 |

### 4.2 输入框

- 白底, `border-[#E2E8F0]`, 圆角12dp
- 聚焦: `border-[#0369A1]` + 0 0 0 3px `rgba(3, 105, 161, 0.1)`
- 错误: `border-[#DC2626]`
- 高度 ≥ 48dp (满足触摸要求)

### 4.3 对话气泡

- 用户: `bg-[#0F172A] text-white`, 右对齐
- AI: `bg-white`, `border-[#E2E8F0]`, 左对齐
- 引用/附件: 气泡内嵌卡片, 可展开

### 4.4 工具/标讯卡片

- `bg-white`, `border-[#E2E8F0]`, 圆角16dp
- 阴影: `rgba(0,0,0,0.04)` y:1 blur:2
- Press: 阴影加深 `rgba(0,0,0,0.08)` + 微缩放

### 4.5 骨架屏 (Shimmer)

- 加载中显示 `bone.bone` → `shimmer.highlight`
- Shimmer 渐变: `#E2E8F0` → `#F1F5F9` → `#E2E8F0`

## 5. 动画规范

| 场景 | 动画 | 时长/参数 |
|------|------|-----------|
| 页面切换 | SlideTransition (水平滑动) | 250ms easeOut |
| 消息入场 | FadeTransition + 位移 8dp | 300ms spring(damping:0.8) |
| AI 回复 | 逐字流式显示 | 实时 |
| 按钮按压 | ScaleTransition 1.0→0.97 | 100ms + HapticFeedback |
| 骨架屏 | 线性渐变 shimmer | 1.5s 循环 |
| 模态/Sheet | 从下上滑 + 遮罩淡入 | 300ms easeOut |
| 下拉刷新 | Material RefreshIndicator | 系统默认 |

**遵循规则：**
- exit 动画比 enter 快 ~60%
- 所有动画可中断 (interruptible)
- 尊重系统 `prefers-reduced-motion`
- 禁止动画影响布局 (CLS-free)

## 6. 数据流

```
┌──────────┐    Dio/SSE    ┌──────────────┐
│  Flutter  │ ←─────────── │  RAGFlow API │
│   App     │   REST/JSON  │  (复用现有)   │
│           │ ←─────────── │              │
└──────────┘    Bearer JWT  └──────────────┘
     │
     ▼
┌──────────────────────────────┐
│  Riverpod Providers          │
│  ├── authProvider            │
│  ├── chatProvider (SSE)      │
│  ├── toolsProvider           │
│  ├── bidProvider             │
│  └── favoritesProvider       │
└──────────────────────────────┘
```

**API 兼容：** 直接复用 RAGFlow 现有后端 API，无需后端改动。
**认证流程：** 邮箱 + 密码 → RSA 公钥加密 → `/api/v1/auth/login` → 返回 JWT → 安全存储。
